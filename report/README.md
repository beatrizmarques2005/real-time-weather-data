# PA48 report (Overleaf project)

Built on the official *Practical Assignment I* template; section order, margins and fonts are unchanged.

1. Run the experiment from the repo root: `python src/practical_assignment.py`
2. Export tables and figures from that run: `python src/export_report_assets.py`
   (writes `report/tables/*.tex` and `report/figures/*.png`)
3. Upload `main.tex`, `references.bib`, `tables/` and `figures/` to Overleaf (or re-upload `tables/` and `figures/` after each new run).
4. Replace every yellow "To be written by the group" box with your own text (interpretation, discussion, recommendations: Handbook Ch. 16).
5. Fill the TODOs: `\GroupCode`, `\SubmissionDate`, the Open-Meteo access date in `references.bib`, and check that the AI Assistance Statement is truthful.
6. Set `\draftinstructionsfalse`, compile, and check the main body is about 6-8 pages.
